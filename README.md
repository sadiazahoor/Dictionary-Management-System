# 📖 Dictionary Management System (C++ | Data Structures & Algorithms)

A simple and interactive **Dictionary Management System** developed in **C++** using a **Singly Linked List**. This project demonstrates the practical implementation of core **Data Structures and Algorithms (DSA)** concepts while providing an easy-to-use console-based dictionary application.

## 🚀 Features

* ➕ Add new words with their meanings
* 🔍 Search words using Linear Search
* ✏️ Update the meaning of existing words
* 🗑️ Delete words from the dictionary
* 📋 Display all dictionary entries
* 📊 Count the total number of words
* 🔤 Sort words alphabetically using Bubble Sort
* ⭐ Track and display the most searched word
* 💡 Prefix Search (Auto Suggestions)
* ✅ Duplicate word detection
* 📈 Search count tracking for each word

## 🛠️ Data Structures & Algorithms Used

## ▶️ How to Run

1. Clone the repository.
2. Open the project in Dev-C++, Code::Blocks, or Visual Studio Code.
3. Compile the source file using a C++ compiler.
4. Run the executable and use the interactive menu.

## 🎯 Project Objective

The objective of this project is to demonstrate the practical implementation of Data Structures and Algorithms by building a simple, efficient, and user-friendly dictionary application. It is suitable for DSA learning, university assignments, and beginner-level C++ projects.
